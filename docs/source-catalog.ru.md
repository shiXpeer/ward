# Обзор источников: реализованные интеграции

Основные интеграции теперь реализованы. Актуальные команды, ограничения и форматы:
[источники и проверка](sources.md), [запуск и проверка компактной базы](verification/compact-0.4.md).
Справочник `configs/source-catalog.json` содержит статус каждого формата.
Дополнительные форматы OVAL/VEX/CSAF и жизненный цикл не требуются для включения
уже работающих Canonical OSV, Debian Tracker и Apple/SOFA; они остаются отдельными
необязательными интеграциями и не объявляются работающими.

## Выбор источников

Ubuntu: Canonical OSV CVE/Livepatch с поддержкой USN по настройке. Debian: полный
Security Tracker; OSV-зеркало используется как дополнительный источник.
macOS: официальный индекс Apple с бюллетенями и структурированный SOFA v1.
Общие данные: полная история NVD, официальный CVE List V5, GitHub Advisory Database,
OSV для распространённых языков, CISA KEV и ежедневный полный EPSS.

Эти источники дополняют друг друга. Повтор одинакового CVE в OSV/GHSA не считается
независимым подтверждением. Сведения о дистрибутивных исправлениях важнее простого
сравнения upstream-версий. SOFA — проект сообщества, не Apple. HTML Apple отражает
ссылки текущего индекса, а не гарантированно всю историю продуктов.

OSV не покрывает полностью Homebrew formulae/casks, все приложения macOS и все
возможные языки/образы. Отсутствие записи не означает безопасность. Контейнеры могут
иметь другую ОС, чем хост: расширенный профиль включает Alpine/Linux/Debian OSV.

## Приватность и ресурсы

Beacon загружает общие данные, одинаковые для всех агентов. Агент скачивает полный
подписанный снимок и не отправляет инвентаризацию. IP и время загрузки видны серверу
доставки; это не обещание сетевой анонимности. Никаких автоматических обновлений ОС,
удалённых команд, загрузки плагинов и повышения привилегий нет.

Архив Canonical содержит примерно 12,3 ГБ распакованного исходного JSON. Beacon
читает его потоком и сохраняет компактные правила отдельно от исходных данных.
Агент получает индексированные файлы с небольшими сжатыми блоками, читает индекс
с диска и скачивает только изменившиеся части. Полностью база в RAM не загружается.
Для всех 18 источников измерено 309 МиБ базы и около 23 МиБ пиковой памяти агента:
[полный отчёт](verification/compact-0.4.md). Сбор пакетов и локальное сопоставление версий работают для поддерживаемых
экосистем. Границы покрытия описаны в [документации сканера](scanning.md).
