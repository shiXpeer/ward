# Огляд джерел: реалізовані інтеграції

Основні інтеграції тепер реалізовані. Актуальні команди, обмеження і формати:
[джерела і перевірка](sources.md), [запуск і перевірка компактної бази](verification/compact-0.4.md).
Довідник `configs/source-catalog.json` містить статус кожного формату.
Додаткові формати OVAL/VEX/CSAF і життєвий цикл не потрібні, щоб увімкнути
вже робочі Canonical OSV, Debian Tracker і Apple/SOFA; вони лишаються окремими
необов'язковими інтеграціями і не оголошуються робочими.

## Вибір джерел

Ubuntu: Canonical OSV CVE/Livepatch із підтримкою USN за налаштуванням. Debian: повний
Security Tracker; дзеркало OSV використовується як додаткове джерело.
macOS: офіційний індекс Apple з бюлетенями і структурований SOFA v1.
Спільні дані: повна історія NVD, офіційний CVE List V5, GitHub Advisory Database,
OSV для поширених мов, CISA KEV і щоденний повний EPSS.

Ці джерела доповнюють одне одного. Повтор однакового CVE в OSV/GHSA не вважається
незалежним підтвердженням. Відомості про виправлення дистрибутива важливіші за просте
порівняння upstream-версій. SOFA — проєкт спільноти, не Apple. HTML Apple відбиває
посилання поточного індексу, а не гарантовано всю історію продуктів.

OSV не покриває повністю Homebrew formulae/casks, усі застосунки macOS і всі
можливі мови та образи. Відсутність запису не означає безпеку. Контейнери можуть
мати іншу ОС, ніж хост: розширений профіль включає Alpine/Linux/Debian OSV.

## Приватність і ресурси

Beacon завантажує спільні дані, однакові для всіх агентів. Агент завантажує повний
підписаний знімок і не надсилає інвентаризацію. IP і час завантаження видно серверу
доставки; це не обіцянка мережевої анонімності. Жодних автоматичних оновлень ОС,
віддалених команд, завантаження плагінів і підвищення привілеїв немає.

Архів Canonical містить приблизно 12,3 ГБ розпакованого вихідного JSON. Beacon
читає його потоком і зберігає компактні правила окремо від вихідних даних.
Агент отримує індексовані файли з невеликими стисненими блоками, читає індекс
з диска і завантажує лише змінені частини. Повністю база в RAM не завантажується.
Для всіх 18 джерел виміряно 309 МіБ бази і близько 23 МіБ пікової пам'яті агента:
[повний звіт](verification/compact-0.4.md). Збір пакетів і локальне зіставлення версій працюють для підтримуваних
екосистем. Межі покриття описані в [документації сканера](scanning.md).
